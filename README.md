# 📝 Тест по радиационной безопасности

Простой браузерный тест из 52 вопросов (по PDF «Тесты РБ.pdf»).

## Возможности
- 🔀 Вопросы и варианты ответов перемешиваются при каждом запуске
- 🔢 Выбор количества вопросов: 10 / 20 / 30 / все 52
- ⏱ Таймер на выбор: без таймера или 60 секунд на вопрос
- 🏆 Проходной балл 70% — «Тест пройден» / «Не пройден»

## Как запустить
Просто открой `index.html` в браузере — ничего дополнительно устанавливать не нужно.

Или подними локальный сервер:
```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

## Как выложить на GitHub
```bash
git init
git add .
git commit -m "Тест по радиационной безопасности"
git branch -M main
git remote add origin https://github.com/ТВОЙ-НИКНЕЙМ/rb-quiz.git
git push -u origin main
```

А ещё можно бесплатно опубликовать прямо из репозитория через **GitHub Pages** (Settings → Pages → Deploy from branch → main → /root) — тогда тест будет доступен по ссылке вида `https://твой-никнейм.github.io/rb-quiz/`.
